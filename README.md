# Орбита — Венера-Юпитер PRO

Production-ready foundation for Telegram dating bot.

> `.env` намеренно не входит в архив. Создайте его из `.env.production.example` и заполните своими секретами.

## Стек
- Python 3.12 / aiogram 3
- PostgreSQL 16
- Redis 7 (FSM + anti-spam + daily like counters)
- Alembic migrations
- Telegram Stars XTR for VIP
- Внутренняя валюта Stars для бонусов и игр
- Автоматическая AI-модерация фотографий с ручным fallback
- Daily local PostgreSQL dump via `pg_dump`
- Telegram admin panel inside the bot
- **Long polling** — без домена, HTTPS, Caddy и webhook на текущем этапе

## Быстрый старт
1. Скопируйте `.env.production.example` в `.env`.
2. Укажите `BOT_TOKEN`, `ADMIN_IDS`, пароль PostgreSQL и `DATABASE_URL`.
3. Для автоматической модерации фото укажите `PHOTO_MODERATION_API_KEY` и оставьте `PHOTO_MODERATION_ENABLED=true`.
4. Запустите:
   ```bash
   docker compose up -d --build
   ```
5. Проверьте логи:
   ```bash
   docker compose logs -f bot
   ```
6. В Telegram отправьте `/admin` с аккаунта, чей ID указан в `ADMIN_IDS`.

Узнать свой Telegram ID можно командой `/myid`.

Админ-панель полностью внутри Telegram. Отдельного сайта для неё нет.

Разделы:

### Внутренние Stars

Внутренние Stars — это отдельная валюта бота и не являются реальными Telegram Stars XTR. Администратор может начислять или списывать их из карточки пользователя; каждая операция сохраняется в `star_transactions` и журнале аудита.

### Игры

В меню пользователя есть 🎮 Игры. Текущая игра — короткая математическая задача без ставок: правильный ответ начисляет 5 внутренних Stars.

## Автоматическая модерация фото

После загрузки фото оно сохраняется со статусом `pending`. Фоновый worker отправляет его AI-провайдеру, после чего:
- безопасные фото автоматически одобряются;
- явно запрещённый контент автоматически отклоняется;
- сомнительные результаты остаются на ручной модерации;
- решение и причина сохраняются в базе;
- пользователь получает уведомление об автоматическом решении.

Если ключ провайдера не задан или провайдер временно недоступен, фото остаётся в очереди ручной модерации.

## Данные и миграции
Схема PostgreSQL создаётся/обновляется автоматически перед запуском бота командой:
```bash
alembic upgrade head
```

После обновления кода обязательно примените миграции перед запуском новой версии.

## Резервные копии
Сервис `backup` создаёт PostgreSQL dump раз в сутки и хранит локальные копии 14 дней. Для полноценного disaster recovery позже рекомендуется добавить off-site/S3-копирование.
